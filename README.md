# 🤖 Agente de IA para Pesquisa de Informações Políticas

Projeto desenvolvido em python utilizando CrewAI para criar um agente de inteligência artificial capaz de pesquisar e organizar informações sobre política a partir de fontes disponíveis na web. 

## Objetivo 

O objetivo deste projeto é aplicar conceitos de Inteligência Artificial, agentes autônomos, pesquisa na web e processamento de informações.

O agente foi desenvolvido para pesquisar dados de pesquisa eleitorais e organizar as informações encontradas de forma estruturada e objetiva.

## Como funciona 

O projeto utiliza um agente especializado em pesquisa que:

1. Recebe uma tarefa de pesquisa;
2. Utiliza um modelo de linguagem para interpretar a tarefa;
3. Realiza pesquisa na web através do Serper;
4. Organiza as informações encontradas;
5. Apresenta os resultados de forma estruturada;
6. Informa as fontes utilizadas quando disponiveis. 

## Tecnologías utilizadas 

- Python 
- CrewAI
- CrewAI Tools
- SerperDevTool 
- python-dotenv
- Git e GitHub
